# Real-Time-Operating-System-RTOS-Using-FreeRTOS
This was designed to introduce and deepen understanding of Real-Time Operating Systems (RTOS) as applied to microcontroller-based embedded systems. The experiment focused on implementing multiple concurrent tasks on an STM32 microcontroller using FreeRTOS, a widely used real-time operating system for embedded applications.
Traditional embedded systems often rely on a single infinite loop structure, where tasks are executed sequentially. While this approach is simple, it becomes inefficient and difficult to manage as system complexity increases. In contrast, an RTOS allows tasks to be divided into independent threads that can run concurrently, improving system responsiveness, modularity, and scalability.
In this laboratory, four independent threads were created to perform specific system functions: displaying temperature data, adjusting LED brightness using a potentiometer, updating an incrementing counter on the LCD, and blinking an LED. Cooperative scheduling was employed to allow each task to voluntarily yield processor time, ensuring fair execution among all threads. Additionally, mutex synchronization was implemented to protect shared hardware resources, particularly the LCD display, from simultaneous access by multiple threads.
Through this activity, students gained hands-on experience with task creation, scheduling, synchronization, and low-power operation in an RTOS-based embedded system. The laboratory emphasized both conceptual understanding and practical implementation, highlighting common challenges encountered in real-time system design.
